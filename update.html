Release notes · 12 Sep 2026

Canva-ready color key, audio, unique files, logs

This update changes the production output. The keyer no longer dumps a silent black-and-white alpha movie. It now writes a unique, full-color clip with the green removed and the original soundtrack still attached — a file you can drop straight into Canva’s video editor.

Agent-first + localhost libraries

Day-to-day run is Grok / Claude / Antigravity (agy) in the terminal, not the GitHub Pages UI. AGENTS.md plus python3 autocrop_rvm.py --watch let the agent monitor input/. Optional docs server: python3 serve.py → http://127.0.0.1:8876/process.html so the browser can reach local output/ and logs/.

What changed

BeforeNow
Black-and-white alpha matte (output_alpha.mp4) Full-color subject, green background removed (transparent alpha)
Audio discarded (OpenCV VideoWriter has no sound) Source AAC is remuxed as Opus on the output
Fixed filename, easy to overwrite Unique name every run: keyed_<clip>_<timestamp>_<id>.webm
Little runtime feedback Live process + performance logs on stdout and in logs/
Meant for DaVinci as a separate matte track Single Canva-ready WebM (VP9 + yuva420p + audio)

Output contract

  • COLOR Subject stays in color. No grayscale matte export.
  • ALPHA Green backdrop is transparent, not black or white.
  • AUDIO Original voice/mic track is kept.
  • UNIQUE Each run gets a new file. Previous exports are left alone.
  • NOT B/W output_alpha.mp4 is no longer produced.

How to run

Full command-prompt and AI-agent instructions live on the Process page.

python3 autocrop_rvm.py
python3 autocrop_rvm.py /path/to/clip.mp4

Where to look after a run

  • output/keyed_*.webm — drop this into Canva → Uploads → timeline
  • logs/process_*.log — crop box, encode FPS, speed, elapsed time, output probe
