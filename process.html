How to run this project

The keyer is a local Python + ffmpeg job. It crops to the green screen, removes the green, keeps the subject in full color, keeps the original sound, and writes a unique Canva-ready .webm with a transparent alpha channel. Every run also writes a process + performance log.

1. One-time setup

In Terminal (or the agent’s command prompt), from this repo:

cd /Users/rifaterdemsahin/projects/chroma-keyer
brew install ffmpeg
python3 -c "from PIL import Image; print('Pillow OK')"

If Pillow is missing: pip3 install pillow. ffmpeg must include libvpx-vp9 (Homebrew’s ffmpeg does).

2. Run it yourself from the command prompt

  1. Put the green-screen clip in this folder, or pass its path.
  2. Run the script. Do not overwrite previous exports — each run creates a new filename.
  3. Watch stdout for crop bounds, encode FPS, and the final output path.
cd /Users/rifaterdemsahin/projects/chroma-keyer

# Uses the sample clip if present, otherwise the newest .mp4/.mov in ./input or .
python3 autocrop_rvm.py

# Or point at any clip
python3 autocrop_rvm.py /path/to/your-greenscreen.mp4

# Optional: neural matting instead of chromakey (needs PyTorch)
python3 autocrop_rvm.py --engine rvm your-clip.mp4

Outputs land in output/. Logs land in logs/.

output/keyed_<clip>_<YYYYMMDD_HHMMSS>_<id>.webm
logs/process_<YYYYMMDD_HHMMSS>_<id>.log

3. Ask an AI agent to run it

Open this repo in Grok Build, Claude Code, Cursor, or Google Antigravity. Paste this into the agent prompt (or type it at the command-prompt agent):

In the chroma-keyer repo, run the green-screen keyer from the command prompt.

Use: python3 autocrop_rvm.py
(or python3 autocrop_rvm.py PATH_TO_CLIP.mp4)

Requirements:
- Keep original audio on the output.
- Keep the subject in full color. Do not export a black-and-white alpha matte.
- Remove the green background (transparent alpha).
- Write a unique filename under output/ so nothing is overwritten.
- Print performance and process logs (also save under logs/).
- The file must be Canva-ready: VP9 WebM with yuva420p alpha + audio.

Agent tip: Set terminal command execution to auto-approve if you want unattended batch runs. The script only needs ffmpeg + Python; it does not open a browser.

4. What a good run looks like

Stdout (and the matching log file) should show:

  • Source size, FPS, duration, and whether audio was found
  • Auto-crop box locked to the green backdrop
  • Encode progress: frame count, elapsed time, speed (e.g. 2.1x)
  • A RUN SUMMARY with the unique output path
========== RUN SUMMARY ==========
Run ID     : 20260912_143015_a1b2c3d4
Engine     : chromakey
Output     : output/keyed_clip_20260912_143015_a1b2c3d4.webm
Format     : VP9 WebM + alpha (yuva420p)
Audio      : opus (source audio preserved)
Color      : full color subject — green background removed
Elapsed    : 18.40s
Log        : logs/process_20260912_143015_a1b2c3d4.log
=================================

5. Drop it into Canva

  1. Open a Canva Video project.
  2. Uploads → Upload files and choose the unique .webm from output/.
  3. Drag it onto the timeline. The green is already gone; the checkerboard/transparent areas let your Canva background, slides, or B-roll show through.
  4. Sound is already on the clip — unmute the track if Canva starts it quiet.

Canva accepts WEBM up to 1 GB. This encoder uses VP9 with an alpha plane (yuva420p) plus Opus audio, which is the usual “transparent video + sound” package for web editors. The keyed clip and the Canva project walkthrough are on Output.

6. Optional flags

python3 autocrop_rvm.py clip.mp4 --similarity 0.10 --blend 0.04 --padding 16
python3 autocrop_rvm.py clip.mp4 --engine rvm
  • --similarity / --blend — loosen or tighten the green key if a halo remains.
  • --padding — extra pixels around the auto-crop box.
  • --engine rvm — Apple Silicon MPS neural matte (person-shaped; may drop props like a mic).
