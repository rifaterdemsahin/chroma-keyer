⚙️ How to run this project

This is a terminal job. An AI agent — Grok, Claude, or Antigravity (agy) — runs the keyer and then quality-assures the file before anything goes to Canva. The HTML pages are optional docs. If you open them at all, use localhost so the browser can reach local clips, logs, and libraries. Do not depend on GitHub Pages for day-to-day work.

4. ✅ Agent QA (required gate)

Every encode is quality-assured by the same class of agent that ran it (Grok, Claude, or agy). autocrop_rvm.py already calls qa.py. The agent must still read the report and look at the sampled frames. No QA PASS → no Canva upload.

python3 qa.py
python3 qa.py output/keyed_….webm
CheckPass means
🔊 audioOpus (or other) soundtrack is on the file — not silent
🪄 alphaalpha_mode=1 so Canva can see through the old green
📦 codecVP9 WebM, not a black-and-white matte movie
🪟 corners-transparentBackdrop is gone (checkerboard / Canva layer shows)
🧑 subject-presentPerson and mic were not keyed out
🌈 color-not-grayscaleSubject is in color
🟩 green-goneOpaque pixels are not leftover green screen

Reports land in logs/qa_*.log plus PNG samples logs/qa_*_t0.png … t2.png. On FAIL the agent re-runs with tighter/looser --similarity / --padding and QAs again.

Example from the checked-in clip:

PASS audio: opus ch=2
PASS alpha: alpha_mode=1 codec=vp9
PASS corners-transparent: mean corner alpha=0.0
PASS subject-present: interior opaque=0.68
PASS color-not-grayscale: chroma=48
PASS green-gone: 0.0%
RESULT PASS

7. 🔧 Optional flags

python3 autocrop_rvm.py clip.mp4 --similarity 0.10 --blend 0.04 --padding 16
python3 autocrop_rvm.py --watch input
  • --watch — agent monitor loop on the inbox.
  • --similarity / --blend — key tightness.
  • --padding — inset of the green crop box.
  • --engine rvm — neural matte (may drop the mic).
