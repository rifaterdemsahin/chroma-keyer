Agent-first · localhost libraries

How to run this project

This is a terminal job. The usual way is an AI agent — Grok, Claude, or Antigravity (agy) — that launches the keyer, watches the log, and reports the unique output path. The HTML pages are optional docs. If you open them at all, use localhost so the browser can reach local clips, logs, and libraries. Do not depend on GitHub Pages for day-to-day work.

1. Agents (default)

Open this repo in the agent. It already has AGENTS.md. Paste the monitor prompt below, or just say “watch input and key new clips.”

Monitor prompt (paste into Grok / Claude / agy)

In chroma-keyer, you are the operator. Do not use the GitHub Pages UI.

1. cd /Users/rifaterdemsahin/projects/chroma-keyer
2. Confirm ffmpeg and Pillow. Install if missing (brew install ffmpeg; pip3 install pillow).
3. If I drop a clip, run:
     python3 autocrop_rvm.py PATH_TO_CLIP.mp4
   To sit on the inbox:
     python3 autocrop_rvm.py --watch
   (watches input/ for new .mp4/.mov)
4. Keep original audio. Keep full color. Remove the green to transparent alpha.
   Unique filename under output/. Never overwrite. Never write a B/W matte.
5. Monitor the job: tail stdout and logs/process_*.log. Report FPS, speed, failures.
6. When done, print the unique output/keyed_*.webm path and the log path.

Let the agent auto-approve terminal commands for this repo. The keyer never needs a browser. The agent’s job is to run and monitor, not to click the static site.

3. One-shot from the command prompt

Same commands the agent runs. You rarely need this if Grok/Claude/agy is already watching.

cd /Users/rifaterdemsahin/projects/chroma-keyer
python3 autocrop_rvm.py
python3 autocrop_rvm.py /path/to/your-greenscreen.mp4
python3 autocrop_rvm.py --watch              # sit on input/
python3 autocrop_rvm.py --engine rvm clip.mp4

Each run writes:

output/keyed_<clip>_<YYYYMMDD_HHMMSS>_<id>.webm
logs/process_<YYYYMMDD_HHMMSS>_<id>.log

  1. Take the unique .webm from output/ (or localhost output library).
  2. Canva → Uploads → Upload files → drop on the timeline.
  3. Background / slides go under this clip. Unmute if Canva starts it quiet.

Walkthrough with the last keyed file: output.html.

6. Optional flags

python3 autocrop_rvm.py clip.mp4 --similarity 0.10 --blend 0.04 --padding 16
python3 autocrop_rvm.py --watch input
  • --watch — agent monitor loop on the inbox.
  • --similarity / --blend — key tightness.
  • --padding — inset of the green crop box.
  • --engine rvm — neural matte (may drop the mic).
